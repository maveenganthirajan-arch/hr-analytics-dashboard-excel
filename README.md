# HR Analytics Dashboard | Employee Attrition Analysis using Excel

## Project Overview

This project uses Microsoft Excel to analyze HR data and explore employee attrition, workforce demographics, job roles, and other employee-related factors. It includes raw data, transformed data, an analysis worksheet, and a dashboard with visualizations.

The objective is to turn employee data into meaningful insights that can support HR reporting and workforce planning.

## Objectives

- Analyze employee attrition and retention patterns.
- Explore workforce distribution by department, gender, age group, and job role.
- Identify employee characteristics associated with attrition.
- Organize and transform raw HR data for analysis.
- Present key findings through charts and an Excel dashboard.
- Practice data analysis and reporting using Microsoft Excel.

## Key Analysis Areas

### 1. Employee Attrition
Explore attrition patterns and compare employees who left with those who stayed.

### 2. Workforce Demographics
Analyze employee distribution by age group, gender, department, and job role.

### 3. Department Analysis
Compare workforce characteristics across departments and job functions.

### 4. Employee Factors
Explore relationships between attrition and factors such as overtime, business travel, job role, and other available employee attributes.

### 5. Dashboard and Visualization
Use charts and visual summaries to communicate patterns in the data.

## How to Use the Project

1. Download `HR Dashboard.xlsx` from this repository.
2. Open the workbook in Microsoft Excel.
3. Review the Raw Data worksheet.
4. Explore the Transform Data and Analysis worksheets.
5. Open the Dashboard worksheet to review the visualizations.
6. If the workbook uses PivotTables, refresh the data when appropriate before interpreting the results.

## Dataset and Limitations

This project analyzes an employee HR dataset for learning and portfolio demonstration. Findings describe patterns in the available data and do not establish causation. The dataset should not be assumed to represent every organization.
